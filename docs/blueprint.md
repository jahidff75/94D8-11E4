# **App Name**: Doxpow Arena

## Core Features:

- Featured Carousel: Display auto-sliding banners with high-quality graphics to promote tournaments, new games, and special offers.
- Game Selection Grid: A grid layout showcasing available games with their icons, names, and live match count.
- Live Match Updates: Real-time updates on match status in 'My Matches' tab (Upcoming, Live, Completed).
- Wallet Management: Securely manage funds with options to add and withdraw cash, displaying a clear breakdown of deposit and winnings.
- Transaction History: Detailed history of all transactions, including deposits, withdrawals, match winnings/losses, with clear labeling and date/time stamps.
- User Profile: Display user information, gaming stats, and access to account settings, match history, and support.
- Referral Program: Implement a referral system to incentivize user growth and offer rewards for inviting friends.

## Style Guidelines:

- Primary color: Vibrant purple (#9400D3) to evoke energy and excitement in the dark mode theme.
- Background color: Dark gray (#212121) for the primary dark mode theme, ensuring visual comfort and enhanced game visibility.
- Accent color: Electric blue (#7DF9FF) for call-to-action buttons, highlights, and interactive elements to create contrast.
- Body and headline font: 'Poppins' (sans-serif) for a clean and easily readable experience.
- Use clean, modern icons that are easily recognizable, with green indicating positive actions (e.g., winnings) and red for errors or losses.
- Employ a fast and responsive layout that provides instant feedback on button presses to create a seamless user experience.
- Subtle animations and transitions to enhance user engagement and provide visual cues without causing lag or delays.
